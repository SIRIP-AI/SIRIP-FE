# SIRIP Frontend

Sirip Frontend

## Prerequisites

- [Node.js](https://nodejs.org/) ≥ 22.12.0

## Running the Application

### Clone the Repository
```bash
git clone https://github.com/SIRIP-AI/SIRIP-FE
```

### Install Dependencies & Run

```bash
npm install
npm run dev
```

The app will be available at `http://localhost:5173`.
